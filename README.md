# Vincent van Dough

Find your next meal in a work of art.

A small Expo app: pick one of three food paintings from The Met, and the app finds recipes for the food it depicts.

Status: Milestone 0.5. This is the Expo starter template. It will be replaced in Milestone 1.

## Preview

Every pull request gets a Vercel preview link, so you can open it in Safari on a phone. Nothing needs installing on your own computer.

## Build it locally (optional)

```bash
npm ci
npx expo start --web      # dev server
npx expo export -p web    # same build Vercel runs; output goes to dist/
```
